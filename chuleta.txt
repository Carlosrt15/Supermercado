Git Cheat Sheet: Resumen de Examen1. Configuración InicialConfigurar nombre global: git config --global user.name "TuNombre"Verificar configuración: git config user.name o git config --list2. Creación y ConexiónCrear repo local: git init SupermercadoEnlazar primer remoto: git remote add origin https://github.com...Añadir segundo remoto (alias): git remote add repo2 https://github.com...Listar remotos conectados: git remote -v3. Flujo de Trabajo (Sync)Comprobar cambios remotos (sin descargar): git fetch originVer estado del repo: git statusComparar ramas (local vs remoto): git diff master origin/masterDescargar e integrar cambios: git pull origin masterSubir cambios al servidor: git push origin master4. Gestión de Conflictos ⚠️Provocarlo: Hacer cambios locales en la misma línea que el remoto y hacer commit.Detectarlo: Al hacer git pull, Git dirá CONFLICT (content).Resolverlo:Abrir el archivo.Borrar las marcas <<<<, ====, >>>>.Dejar el texto final deseado.Finalizar:git add <archivo>git commit -m "Conflicto resuelto"git push origin master💡 Tips para el examen:master vs main: Fíjate siempre en el nombre de tu rama en la terminal (entre paréntesis azul). Si pone (master), usa master en los comandos.fetch vs pull: Recuerda que fetch es para "mirar" y pull es para "traer y mezclar".Historial gráfico: Si te piden ver cómo se unieron las ramas, usa:git log --oneline --graph --all
